# ロッククイズ（Android）

英語⇔日本語の単語クイズを、端末のロック解除直後に全画面で出すアプリ。
指定した問題数に正解するまで閉じられません。

## APKのビルド（GitHub Actions）
1. このリポジトリをGitHubにpushする（mainブランチ）。
2. 「Actions」タブで **Build APK** が走る（初回は5〜10分ほど）。
3. 成功したら、リポジトリの「Releases」に `Build N` ができる。`app-debug.apk` をタップしてダウンロード → インストール。
   （提供元不明アプリのインストール許可が必要）
4. 手動で再ビルドしたい時は、Actions → Build APK → Run workflow。

## 使い方
1. アプリを開き、単語ファイルを読み込む。
   - ファイル1つ: `english : 日本語` の行（`【Drill 1】` のような見出しはカテゴリ）
   - ファイル2つ: 日本語だけのファイルと英語だけのファイル（1行ずつ対応）
2. 「他のアプリの上に表示」を許可。
3. 「今すぐテスト表示」で動作確認 → 「ロッククイズを有効にする」をオン。

## 事故防止
- 最初は問題数を1にしてテストする。
- 出られなくなったら `adb uninstall com.example.lockquiz`、または再起動してセーフモードでアンインストール。
- 単語が0件の時はクイズを出さない。

## AI判定サーバー（任意）
`server/worker.js` をCloudflare Workersに置き、環境変数 `ANTHROPIC_API_KEY`（と任意で `APP_TOKEN`）を設定。
アプリのURL欄にWorkerのURL、トークン欄に `APP_TOKEN` を入れる。未設定でも端末内の判定だけで動く。
